# Keyboard Sound — صدای دلخواه برای کلیدها

ابزار دسکتاپ ویندوز برای اختصاص فایل‌های WAV و MP3 به کلیدهای کیبورد، با پروفایل‌های مستقل، کنترل صدا و اجرای کنار ساعت.

## شروع

۱. نصب‌کننده را از بخش Releases دانلود و نصب کن.
۲. برنامه را باز کن و فایل صوتی خودت را Import کن.
۳. یک کلید و یک صدا انتخاب کن و Assign to selected key را بزن.
۴. برای توقف پخش، Global sounds enabled را خاموش کن؛ برای خروج کامل از منوی کنار ساعت Exit را انتخاب کن.

نصب اولیه کتابخانه خالی دارد. پک Fun اختیاری است؛ پس از استخراج، برنامه را کامل ببند و Install-Pack.cmd را اجرا کن. مجوز CC0 و نام منابع همراه پک هستند.

## حریم خصوصی و محدودیت‌ها

برنامه برای تشخیص کلیدها از hook محلی ویندوز استفاده می‌کند. در سورس فعلی تاریخچه تایپ ذخیره نمی‌شود و مسیر ارسال شبکه‌ای وجود ندارد. تنظیمات و صداها در LocalAppData/KeyboardSound نگه‌داری می‌شوند. عملکرد در صفحه ورود، محیط امن ویندوز یا برنامه‌های دارای دسترسی بالاتر تضمین نشده است.

نسخه فعلی برای ویندوز x64، از Windows 10 build 19041 به بعد طراحی شده؛ نصب‌کننده امضای دیجیتال ندارد. گزارش تست قبلی، تأیید سازگاری روی همه دستگاه‌ها نیست.
